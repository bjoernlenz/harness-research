004 Primary Substrates

The current corpus suggests that primary_substrate is becoming one of the strongest organizing dimensions in the observatory.

Patterns

  • Repository / diff substrate: Aider
  • Terminal / shell substrate: Claude Code, Pi
  • IDE / mode / remote environment substrate: Cursor
  • Graph / state substrate: LangGraph
  • Agent-routing substrate: OpenAI Agents SDK
  • Team / event substrate: AutoGen
  • Kernel / plugin substrate: Semantic Kernel
  • Data / retrieval substrate: LlamaIndex
  • Sandbox / embodied tool substrate: OpenHands
  • Type / contract substrate: PydanticAI

Best Representatives

  • Repo-close substrate: Aider
  • Terminal substrate: Claude Code
  • Graph substrate: LangGraph
  • Routing substrate: OpenAI Agents SDK
  • Team substrate: AutoGen
  • Kernel substrate: Semantic Kernel
  • Data substrate: LlamaIndex
  • Sandbox substrate: OpenHands

Gravity Wells

  • repository-as-memory
  • graph-orchestration
  • extension-driven-runtime
  • data-as-cognitive-substrate
  • kernel-as-cognitive-spine

Blurry Distinctions

  • Pi vs Claude Code: both shell-close, but one is minimal-core and the other permission-composable
  • Cursor vs OpenHands: both broaden agent embodiment, but in different bodies
  • OpenAI Agents SDK vs Semantic Kernel: both route capabilities, but through different centers of gravity
