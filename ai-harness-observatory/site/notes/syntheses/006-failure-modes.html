006 Failure Modes

Failure modes are already revealing where each harness pays its real architectural cost.

Patterns

  • Context and repo drift: Aider, Claude Code
  • Mode or environment confusion: Cursor, OpenHands
  • Graph or workflow sprawl: LangGraph, LlamaIndex
  • Handoff or routing mismatch: OpenAI Agents SDK, AutoGen
  • Schema or middleware heaviness: PydanticAI, Semantic Kernel
  • Extension fragmentation: Pi

Best Representatives

  • Repo-local drift: Aider
  • Graph sprawl: LangGraph
  • Handoff mismatch: OpenAI Agents SDK
  • Team sprawl: AutoGen
  • Sandbox heaviness: OpenHands
  • Schema rigidity: PydanticAI
  • Retrieval overload: LlamaIndex

Blurry Distinctions

  • Cursor and OpenHands both fail through environment breadth, but Cursor’s problem is boundary management while OpenHands’ is body heaviness
  • Semantic Kernel and OpenAI Agents SDK both distribute capability, but one fails through middleware indirection and the other through routing complexity
