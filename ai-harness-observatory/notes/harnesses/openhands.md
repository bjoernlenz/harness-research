# OpenHands

## Essence

OpenHands gives a coding agent a broad practical body: code, shell, browser, APIs, repositories, and configurable sandboxes across cloud, GUI, CLI, and headless modes.

## Architectural Worldview

This system assumes that useful software agency needs a real environment to act inside. It wants the agent to work with many of the same surfaces a human developer does.

## Center of Gravity

Embodied tooling, sandboxed execution, and environment customization.

## Complexity Lives In

- Sandbox design
- Repository integration
- Tool breadth
- Agent customization

## Primary Substrate

- Sandbox
- Repository
- Tools
- Agent skills

## Trust Model

- Environment control
- Supervision
- Sandbox boundaries

## Memory Model

Memory seems to live mainly in repository state, session context, setup scripts, and customization layers rather than in a clean typed memory core.

## Human Role

The human is an operator and environment designer, deciding what body, tools, and setup the agent should inhabit.

## Playfulness / Surprise

The lively move is how much body it gives the agent. OpenHands feels less like a chat wrapper and more like a configurable developer organism.

## What It Makes Easy

- Letting an agent act across a broad developer environment
- Customizing behavior with MCP, microagents, and setup scripts
- Moving between cloud, GUI, CLI, and headless modes

## What It Makes Awkward

- Keeping the system lightweight
- Containing the complexity that comes with broad embodiment

## Failure Modes

- Sandbox complexity
- Tool-surface overload
- Configuration drift

## What It Refuses

- A narrow single-interface agent body
- Restricting coding agency to chat-only abstraction
- Separating the agent from the practical tooling of development work

## Core Tension

Its strength is giving the agent a full practical body. Its tradeoff is that the richer the body becomes, the harder it is to keep behavior simple, predictable, and lightweight.

## Archetype

The Agent OS

## Representative For

- Fully embodied coding agent
- Sandbox-centered agent platform
