## Current Archetypes

- The Cognitive Shell: Claude Code, Pi
- The Graph Weaver: LangGraph
- The Multi-Agent Theater: AutoGen
- The Tool Router: OpenAI Agents SDK, Semantic Kernel
- The Agent OS: OpenHands
- The Typed Runtime: PydanticAI
- The Research Operator: LlamaIndex

## Emerging Primary Substrates

- Repository / git / diff
- Terminal / shell / permissions
- IDE context / modes / remote environment
- Graph / state / checkpoints
- Agent objects / tools / handoffs / traces
- Teams / events / extensions
- Kernel / plugins / connectors
- Data / indexes / workflows
- Sandbox / developer tools

## Emerging Trust Models

- Trust through closeness: repo, terminal, visible diffs
- Trust through structure: graphs, types, guardrails, traces, kernels
- Trust through supervision: modes, environments, sandbox boundaries
- Trust through data grounding: retrieval relevance and workflow structure

## Emerging Failure Modes

- Context drift
- Graph or workflow sprawl
- Handoff mismatch and routing confusion
- Schema or validation rigidity
- Sandbox / environment heaviness
- Extension and connector fragmentation
- Retrieval miss and data-substrate overload

## Strongest Repeated Concepts

- repository-as-memory
- git-as-cognition
- graph-orchestration
- human-in-the-loop
- permissioned-agency
- extension-driven-runtime
- data-as-cognitive-substrate
- traces-as-residue

## Weakest Schema Fields

- `representative_for`: useful but still slightly fuzzy in phrasing
- `trust_model`: promising, but not yet normalized enough for strict comparison
- `failure_modes`: informative, but granularity varies between harnesses
- `human_role`: valuable, but currently too free-form for visualization

## Unclear Or Conflicting Classifications

- Cursor sits between repo companion and IDE agent rather than fitting cleanly in one lane
- Semantic Kernel is partly an agent framework and partly cognitive middleware
- OpenHands can read as coding agent, agent platform, or agent OS
- Pi and Claude Code are close cousins, but Pi’s minimal-core identity is distinct enough to preserve
- LlamaIndex may want its own stable family beyond generic agent framework
